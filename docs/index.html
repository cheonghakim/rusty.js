🦀 Rusty · JS ownership checker

JS 코드, 소유권으로
읽어보세요.

Rusty는 ref / mut / move / clone 네 가지만 얹어서, "이 값을 지금 누가 읽고 있고 누가 쓰고 있고 누가 가져갔는지"를 실행 전에 정적으로 추적합니다. 아래에서 실제로 잡히는 버그 3가지를 한 줄씩 실행해보세요.

ref()읽기 전용으로 빌리기
mut()일시적으로 수정 권한 빌리기
move()소유권을 완전히 넘기기
clone()독립된 복사본 만들기

소유권 상태

설치

$ npm install @cheonghakim/rusty.js
$ npx rusty check

CI에서든 에디터에서든, 이 정적 분석이 실행 전에 같은 진단을 냅니다.
